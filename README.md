# SymSvel Tooling

SymSvel development tooling Symfony bundle.

Composer package: `symsvel-framework/tooling`.

Development-only bundle, installed via `require-dev` and enabled in `dev` and `test` only. Depends on `symsvel-framework/core`; Core must never depend on Tooling.

This repository is initialized as a minimal Symfony bundle. Feature extraction from `symsvel-back` will follow in separate PRs.
